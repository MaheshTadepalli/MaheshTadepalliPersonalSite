# Deployment

This is a Next.js portfolio website for Mahesh Tadepalli.

## Environment

Set `NEXT_PUBLIC_SITE_URL` to the production URL before deployment.

## Build

```bash
npm install
npm run build
```

## Content Checks

- Update profile data in `config/site.ts`
- Update projects in `data/projects.ts`
- Update resume entries in `data/experience.ts`
- Keep the resume PDF at `public/resume/Mahesh_Tadepalli_Resume.pdf`
- Keep the profile photo at `public/mahesh-tadepalli.jpeg`
