# Mahesh Tadepalli - Portfolio Website

Personal portfolio website for Mahesh Tadepalli, an M.Tech student at IIT Bombay focused on software development, data science, machine learning, computer vision, and big data applications.

## Highlights

- Config-driven profile content in `config/site.ts`
- Resume sections powered by `data/experience.ts`
- Project cards powered by `data/projects.ts`
- Technical skills powered by `data/skills.ts`
- Profile photo and resume stored in `public/`

## Development

```bash
npm install
npm run dev
```
